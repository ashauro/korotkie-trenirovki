# Короткие тренировки

Веб-приложение (PWA) с ежедневной короткой силовой тренировкой: 5, 10 или 15 минут, дома с гантелями или в поездке без оборудования. Ставится на главный экран телефона и работает без интернета.

Сборки нет: это обычные статические файлы. Папку можно выложить на любой статический хостинг как есть.

## Файлы

| Файл | Что в нём |
|---|---|
| `index.html` | Страница: мета-теги, манифест, каркас экранов |
| `styles.css` | Все стили, светлая и тёмная темы, шрифты |
| `app.js` | Вся логика: упражнения, план, плеер тренировки, очки и награды, задания, настройки |
| `theme.js` | Включает сохранённую тему до первой отрисовки |
| `sw.js` | Сервис-воркер: хранит приложение на устройстве для работы офлайн |
| `manifest.webmanifest` | Название, иконки и цвета для установки на телефон |
| `icons/`, `fonts/` | Иконки приложения и шрифты (Onest, Sofia Sans Condensed) |

## Запуск на компьютере

```bash
python3 -m http.server 8765
```

Затем открыть http://localhost:8765. Открывать `index.html` двойным щелчком не стоит: без сервера не работает офлайн-режим.

Сервис-воркер держит старые файлы, пока не сменится версия. Если правки не видны, откройте страницу в приватном окне или очистите данные сайта.

## Выкладка

Нужен хостинг с HTTPS: без него телефон не даст установить приложение. Подойдёт GitHub Pages, Cloudflare Pages, Netlify или любой другой статический хостинг. Команда сборки не нужна, корень сайта — эта папка. Все пути относительные, поэтому приложение работает и в подпапке (например, `user.github.io/trenirovki/`).

## Выпуск обновления

1. Поменять `VERSION` в `sw.js` и `APP_VERSION` в `app.js` на одно и то же новое значение.
2. Выложить файлы.

Телефон заметит новую версию при следующем открытии и покажет кнопку «Обновить». Без смены версии установленные приложения останутся на старых файлах.

## Данные

Прогресс хранится только на устройстве, в `localStorage` под ключом `kt-v2`. Сервера и аккаунтов нет. Перенос на другой телефон: «Настройки» → «Данные» → «Сохранить копию» и «Загрузить копию». Файл копии при загрузке проверяется, неизвестные поля отбрасываются.
